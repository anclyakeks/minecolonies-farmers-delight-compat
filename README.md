# MineColonies + Farmer's Delight Compatibility

A compatibility addon for Minecraft 1.21.1 that lets MineColonies workers use Farmer's Delight crops, ingredients, and meals in normal colony workflows

## Features

- Adds MineColonies recipes for Farmer's Delight food chains: Chef, Baker, Farmer, Planter, and Fletcher
- Integrates Farmer's Delight meals with Restaurant menus and colony food values
- Lets compatible MineColonies and Farmer's Delight ingredients satisfy the same colony requests
- Adds farmer support for cabbage, tomato, onion, mushrooms, Rich Soil Farmland, and rice paddies

## Requirements

| Component | Required version |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.238 or newer within 1.21.1 |
| MineColonies | 1.1.1367 or newer |
| Farmer's Delight | 1.3.2 or newer |

## Installation

1. Download the release JAR
2. Put it in the server's `mods` directory alongside MineColonies and Farmer's Delight
3. Restart the server

The compatibility JAR is server-side. Clients with this JAR can see UI in crops

## Using rice fields

Select rice for a MineColonies field and create source-water cells one block deep directly above dirt inside its bounds. The farmer plants rice in the water and harvests a mature panicle without destroying the submerged stalk
